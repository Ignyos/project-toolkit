Project Toolkit

Scaffold, govern, and release any software project using AI agents guided by architectural specs — with zero repository clutter or permanent dependencies.

Quick Start

Copy this prompt and paste it into VS Code Copilot Chat in any project workspace to begin:

Please bootstrap or reconcile this repository using the Ignyos Project Toolkit.

Follow these steps:
1. Run `git clone --depth 1 https://github.com/Ignyos/project-toolkit .scratch-toolkit` in the terminal to shallow-clone the toolkit.
2. Run `.\.scratch-toolkit\bootstrap.ps1` in PowerShell to begin the interactive interview (choose Full Profile or Project Management Only, then Greenfield or Existing).
3. Follow the directives output by the bootstrap script and profile documents (`architecture.md`, `requirements.md`, `implementation-steps.md`, `acceptance-checklist.md`).
4. Apply origin breadcrumbs per `shared/breadcrumb-spec.md` to generated files.
5. Reconcile or set up `AGENTS.md` and `PM/` project management structure per the profile guidelines.
6. Once implementation and acceptance verification are complete, delete the `.scratch-toolkit` directory.

Why Project Toolkit?

🤖

Documentation as Executable Rules

Instead of stale templates or rigid shared scripts, project profiles define architectural requirements. AI agents generate fresh, idiomatic code tailored specifically to your project's constraints.

🧹

Zero Repository Clutter

The toolkit is shallow-cloned temporarily into a .scratch-toolkit/ directory during setup and deleted immediately upon completion. Nothing remains in your repo except a 5-line origin breadcrumb header.

📋

AI-Driven Project Management

Built-in PM/ conventions (backlog → current → release-candidate-dev → release-candidate → completed) keep AI sessions strictly aligned with current priorities without status drift.

🚀

Dual-Lane Release Architecture

Strict dev and production lane isolation ensures dev builds never leak pre-production code or dev subdomains into live releases.

Supported Profiles

.NET

dotnet-windows-desktop

Multi-project .NET solution with desktop host, ASP.NET Core API, Web frontend, Inno Setup installer, SHA256 checksums, and update manifest polling.

Web / PWA

vanilla-js-github-pages-spa

Vanilla JS Single Page Application hosted on GitHub Pages with service worker caching, dual-repo dev/live deployment, and timestamp versioning.

PM Only

project-management-only

Adopt the AI-driven PM/ folder structure and AGENTS.md direction rules into an existing codebase with established CI/CD pipelines.
